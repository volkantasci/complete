# Complete

Complete rebuilds the functionality and the look of Odoo Enterprise features as free modules for Odoo Community Edition. Every module is licensed AGPL-3.0-only, targets the latest Odoo release line (currently 20.0), and ships with tests, documentation, and Complete's own screenshots.

Complete contains no Odoo Enterprise code; every module is written from behavioural specifications through a clean-room process.

Read the [process description](docs/process.md) to see how that works, the [licensing notes](docs/licensing.md) for what may and may not enter the repository, and [CONTRIBUTING.md](CONTRIBUTING.md) before sending a change.
