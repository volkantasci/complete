Employees Mobile

With the Employees application, My Preferences sends the account details you just saved (name, login, picture) to the native app before the page reloads for a language change.

  • Works only inside the native apps; nothing changes in a normal browser.
  • A missing or failed answer from the app never blocks the preferences dialog.

The module installs itself with Employees and Mobile.

See the module README.md for scope, provenance and tests.
