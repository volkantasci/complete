Point of Sale Camera Badge Login

On the point of sale login screen with employee login, the badge button of the PIN step opens the camera and reads an employee badge.

  • The code is handled like one from a hardware scanner: an allowed employee is logged in.
  • Works in any browser that offers camera access, inside the app or not.
  • An empty code shows a notice asking to scan the badge again.
  • Set up with the employee login on the shop, the allowed employees and a Badge ID on each employee.

The module installs itself with Point of Sale Employees and Mobile.

See the module README.md for scope, provenance and tests.
