Web Shell

Gives the web client a home menu: a grid of your applications that is the first screen after login and that you can call up over any open application.

It also adapts the top bar and the mobile navigation to it, and lets each user choose a System, Light or Dark theme.

  • Home menu with keyboard navigation and type-to-search.
  • Tiles that each user can reorder by drag and drop.
  • Top bar with a home button and a back button over an open application.
  • Mobile sidebar with an "All Apps" entry.
  • Administrator message above the tiles.
  • Personal Theme preference: System, Light or Dark.
  • View switcher highlight, sticky kanban column headers and a pivot without hover tooltips on small screens.

The module also carries the theme: one set of colour roles with a light and a dark value, a complete dark stylesheet, and restyled top bar, home menu, forms, lists, kanban, calendar, charts, dialogs and the login page. Native controls such as scroll bars follow the chosen scheme. Other modules can change the roles to retheme the web client.

See the module README.md for scope, provenance and tests.
