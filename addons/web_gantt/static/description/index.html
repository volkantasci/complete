Gantt View

A read-only timeline view for the web client. Records are drawn as bars on a time grid, in rows that can be grouped by any field. Any window action can list it among its views.

  • Day, week, month, quarter and year ranges, a custom range, previous, next and Today.
  • Grouping on several levels, folding of group rows, one row per record in sparse mode, paging of groups.
  • Bars coloured, marked and filled by fields of the record, a popover with a summary, an optional total row.
  • Capacity bars, unavailable periods and folded columns, supplied by the modules that host the view.
  • Sample data and empty states, phone layout, light and dark look.

Editing, dependencies and the HR and time-off views come in later releases.

See the module README.md for scope, provenance and tests.
