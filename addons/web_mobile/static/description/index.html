Mobile

Lets the web client work with the native Complete apps for Android and iOS. Inside an app, the page offers features that use the phone; in a normal browser nothing changes.

  • Add to Home Screen, and Switch/Add Account in place of Log out.
  • The application list and your account details kept in step with the app.
  • Downloads handed to the app, history moves, the device back button and error reports.
  • Files shared into the app open the Create dialog, with a clear notice when they cannot be loaded.
  • One row per application on the home menu inside the iOS app.
  • An event channel for the hardware readers of the app.

The module installs itself with the web client and adds no menu and no setting.

See the module README.md for scope, provenance and tests.
