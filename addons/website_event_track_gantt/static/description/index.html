Event Tracks Timeline

A Gantt view for the tracks of an event. The module installs by itself when the event tracks application and the Gantt view are both present, and adds no menu, group or setting.

  • The event's Tracks button opens the tracks on the event's first day and on a day, week, month or year range that fits the event. In developer mode, Events > Tracks opens every event's tracks on the Year range, grouped by location.
  • Pills move, copy and resize with Undo. A popover shows the title, the start and the speaker, when there is one.
  • The track dialog has a footer of Save, Discard, Unschedule and Delete with a confirmation, by the user's access rights on tracks; the stage bar, the wishlist button and the publish button are left out.
  • Unschedule empties the start and end of a track and keeps its duration.
  • Events administrators, Events users and read-only users each see what their rights allow. The phone has its own layout.

See the module README.rst and docs/modules/event_track_gantt.md.
